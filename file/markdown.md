# ⚡️IP质量评分系统指南

IP质量分从 `100分` 起评，根据多个维度加减分，最终得出 `0~100` 的网络信誉分数。它可用于预测网站拦截风险、账号风控概率等场景。

---

## 🧠 核心评分逻辑：五维度评估

### ① 🔌 IP类型（权重 30%）
- ✅ IPv6 地址：`+5`（质量优）
- ⚠️ 代理/VPN：`-25`（拦截风险高）
- 🖥️ 服务器IP（IDC）：`-15`
- 🏠 家庭宽带：`+5`（可信度高）
- 🏢 企业公网：`+2`

### ② 🗺️ 地理一致性（权重 20%）
- ❌ 信息缺失（如无国家城市）：`-10`
- 🧭 坐标异常（如 0.0）：`-8`
- ✅ 信息完整：`+0`

### ③ 🌐 ISP信誉（权重 25%）
- ⭐️ 知名服务商（Google、Amazon、Microsoft、Cloudflare、中国电信等）：`+8`
- ⚠️ 可疑标签服务商（如含 VPN/Hosting/Anonymous）：`-20`
- ❓ 无 ISP 信息：`-5`
- 📡 普通运营商：`+0`

### ④ 🏗️ 网络基础设施（权重 15%）
- 🏛️ 老牌 ASN（编号 < 1000）：`+5`
- 🆕 新 ASN（编号 > 60000）：`-3`
- 🪪 标准 ASN：`+0`
- ❌ ASN 缺失：`-8`

### ⑤ 🔐 安全风险（权重 10%）
- 🧱 内网地址（如 192.168.x.x）：`-15`
- 🚫 保留 IP 段：`-10`
- 🌍 公网标准 IP：`+0`

---

## 📈 评分等级及拦截风险

| 🏅 分数范围 | 等级   | 📊 描述                     | 🚨 拦截风险 |
|------------|--------|----------------------------|-------------|
| 90–100     | 优秀   | 信誉极高，极少被拦截        | 极低        |
| 80–89      | 良好   | 表现稳定，较少触发风控      | 低          |
| 70–79      | 一般   | 有潜在拦截风险              | 中等        |
| 60–69      | 较差   | 容易被识别为机器人          | 高          |
| 0–59       | 很差   | 高风险，常被屏蔽或限制      | 极高        |

## 🚀 实际应用场景

**优质 IP（80+分）适合：**
- 🤖 网页爬虫与数据采集
- 📱 社交平台账号管理
- 🛍️ 电商运营与脚本交易
- 📢 广告投放与自动营销

**低分 IP（≤60分）风险：**
- ❌ 验证码频繁触发
- 📛 账号易被封禁
- ⛔️ 接口访问限制
- 📉 SEO 排名受影响

---

## 🎯 提升 IP 分数建议

- ⛔️ 避免代理/VPN 使用（最大扣分项！）
- ✅ 选用中国电信、移动、联通等 **知名 ISP**
- 🏠 使用家庭宽带而非服务器托管 IP
- 🌎 保证 IP 具备完整地理位置信息
- 🌐 优先启用 IPv6（加分项）
